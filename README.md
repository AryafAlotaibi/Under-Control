# UnderControl
### Agentic AI for Project Diagnosis & Recovery

## Project Overview

UnderControl is a multi-agent system designed for project diagnosis and recovery planning.

The system analyzes uploaded project data, identifies potential issues and bottlenecks, retrieves relevant supporting evidence, and evaluates candidate recovery actions through what-if simulation.The results are presented through an interactive Streamlit dashboard, providing structured project diagnosis and recovery guidance.

## Problem Statement

Project data can contain large amounts of information related to tasks, statuses, priorities, assignees, timelines, and dependencies. Analyzing this information manually can make it difficult to identify the underlying causes of delays, detect bottlenecks, and determine appropriate recovery actions.

UnderControl addresses these challenges by combining project data analysis, evidence retrieval, and recovery simulation within a unified workflow.

## Key Features

- **Project Data Analysis:** Processes uploaded project CSV files and standardizes project information.
- **Project Diagnosis:** Identifies potential issues, bottlenecks, dependencies, and schedule risks.
- **Evidence Retrieval:** Uses current-project information and historical project cases to support analysis.
- **Recovery Simulation:** Evaluates candidate recovery actions through what-if simulation.
- **Recovery Planning:** Generates structured findings and recovery guidance based on analysis and simulation results.
- **Interactive Dashboard:** Presents project insights and simulation results through a Streamlit interface.

## How It Works

1. **Upload:** Upload project data in CSV format.
2. **Analyze:** Standardize project information and examine the current project state.
3. **Retrieve Evidence:** Gather relevant information from current project data and historical cases.
4. **Simulate:** Evaluate candidate recovery actions and compare simulation results.
5. **Review:** Explore the diagnosis, simulation outcomes, and recovery guidance through the dashboard.
